# Skill: Deploy App

## Objective
Your goal as DevOps is to intelligently package the application and fire up a server based on the chosen stack (Laravel / PHP).

## Instructions
1. **Stack Detection**: Inspect the `Technical_Specification.md` and the `.csproj` file to figure out what stack is being used.

2. **Install Dependencies & Build**: Use your native terminal to navigate into the project and run `laravel restore` followed by `laravel build`.

3. **Host Locally**: Execute `laravel run` to start the backend server locally.
4. **Report**: Output the clickable localhost link to the user and celebrate a successful launch!
